# 知序 Ordo - 官方宣传落地页与部署套件

本项目为跨平台、离线优先待办应用「**知序 Ordo (Order & Priority)**」的官方宣传落地页。已全面优化电脑端（Desktop）、平板端（Tablet）与移动手机端（Mobile）的全响应式自适应体验。

---

## 📱 全设备响应式自适应亮点

1. **多端自适应布局体系**：
   - **桌面端 (≥1024px)**：经典左右分栏、首屏 3D 悬浮微动手机机模、5 列宣传物料沉浸式画廊；
   - **平板端 (768px ~ 1023px)**：3 列响应式画廊，图文比例自动平滑收缩；
   - **移动手机端 (≤640px)**：
     - **流体文字与间距**：标题采用 `clamp()` 流体响应式排版，在 360px ~ 430px 各主流机型上均严整对齐，告别生硬折行；
     - **极简顶栏与折叠抽屉**：窄屏手机上精简顶栏间距，提供汉堡包折叠抽屉菜单；
     - **2 列双瀑布画廊**：移动端应用商店标准双列排布，大图比例与手指滑动极度舒适；
     - **移动端专属下载弹窗**：带原生半透明磨砂背景遮罩（Backdrop）、独立右上角关闭按钮 `×`，支持触摸点击与快速返回。
2. **零依赖单文件版体积突破 (<2MB)**：
   - 包含 18 张 100% 全尺寸高保真原图，通过单例字典消除冗余及高保真 WebP 编码，文件控制在 **1.87 MB**；
   - 支持离线、断网运行，任何平台单个 HTML 文件双击即用。
3. **二维码社群交互**：
   - 桌面端悬浮即现防断开，移动端轻触弹出居中弹窗；
   - 支持直接点击二维码调用全屏 Lightbox 大图灯箱放大扫码。
