# 滴答清单（TickTick）UI 设计分析报告

## 1. 整体设计语言

### 1.1 视觉风格
- **风格定位**：现代扁平设计 + 轻微拟物质感的混合体
- **整体气质**：简洁专业、略带温暖亲和力，既不过于冷峻也不过于可爱
- **圆润程度**：中等偏圆润，卡片和弹窗采用较大圆角（约12-16px），按钮采用中等圆角（约8px）
- **层次感**：通过微妙的阴影和半透明遮罩创造Z轴层次，非纯扁平

### 1.2 色彩方案

| 角色 | 色值（估算） | 用途 |
|------|-------------|------|
| **主背景色** | #F5F5F5 / #FAFAFA | 页面底层背景，浅灰白色 |
| **卡片/弹窗背景** | #FFFFFF | 纯白色，用于内容区域 |
| **主强调色** | #4A90E2 / #5B8DEF | 蓝色系，用于FAB按钮、选中态、可点击链接 |
| **次要强调色** | #FF9500 / #FFA500 | 橙色系，用于数字标签（如"12"）、今天图标 |
| **危险操作色** | #FF3B30 / #FF453A | 红色系，用于删除操作 |
| **成功/确认色** | #34C759 / #30D158 | 绿色系，用于分享、完成状态 |
| **警告/置顶色** | #FF9F0A / #FFCC00 | 黄色系，用于置顶操作 |
| **标签背景色** | #FFE5E5 / #FFEBEE | 浅粉色，用于任务标签背景 |

#### 文字颜色层级
| 层级 | 色值（估算） | 用途 |
|------|-------------|------|
| 主标题文字 | #1A1A1A / #000000 | 任务标题、页面标题 |
| 正文文字 | #333333 / #2C2C2E | 列表项文字、菜单文字 |
| 辅助文字 | #666666 / #8E8E93 | 日期、描述、数量 |
| 占位符文字 | #999999 / #AEAEB2 | 输入框提示文字 |
| 禁用文字 | #C7C7CC | 已完成任务、不可操作项 |

### 1.3 圆角风格
- **弹窗/卡片**：大圆角（12-16px），顶部常为圆角
- **按钮**：中等圆角（8px），FAB为完全圆形
- **输入框**：小圆角（4-8px）
- **标签**：完全圆形或大圆角药丸形

### 1.4 阴影使用
- **弹窗阴影**：轻微但明显的投影（约0 4px 12px rgba(0,0,0,0.15)）
- **FAB阴影**：较明显的投影，增强悬浮感
- **卡片阴影**：极轻微或无阴影，依赖背景色差区分层次
- **遮罩层**：半透明灰色（约rgba(0,0,0,0.4)），用于背景变暗

### 1.5 字体层级（估算）

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| 页面标题 | 20-22sp | Bold (700) | 侧边栏标题、清单名称 |
| 任务标题 | 18-20sp | Bold (700) | 任务详情中的任务名 |
| 列表项标题 | 16-17sp | Medium (500) | 侧边栏菜单项、操作菜单项 |
| 辅助信息 | 14-15sp | Regular (400) | 日期、描述、进度百分比 |
| 标签文字 | 12-13sp | Medium (500) | 任务标签、数量标记 |
| 小字注释 | 11-12sp | Regular (400) | 工具栏图标下方文字 |

## 2. 主页面布局分析

### 2.1 页面结构

#### 顶部栏
- **高度**：约56-64dp（标准Material高度）
- **构成**：
  - 左侧：汉堡菜单图标（≡）/ 返回箭头（←）
  - 中间：清单emoji图标 + 清单名称（粗体）
  - 右侧：搜索图标、通知图标、设置图标（三个点菜单展开时隐藏）
- **背景**：与页面背景一致（浅灰色），无明显分割线

#### 内容区
- **背景色**：浅灰色（#F5F5F5）
- **任务卡片**：白色背景，轻微圆角，有时间戳图标（右上角）
- **间距**：卡片之间有明显间距（约8-12dp）

#### 底部导航栏
- **高度**：约56dp
- **图标数量**：5个（从左到右：勾选、日历、时钟、网格、更多）
- **图标风格**：线性图标，约24-28px大小
- **选中态**：图标填充为蓝色，背景可能有轻微高亮
- **未选中态**：灰色线性图标

### 2.2 侧边栏抽屉样式

#### 宽度
- **占屏比例**：约75-80%屏幕宽度
- **右侧遮罩**：半透明灰色，可点击关闭

#### 顶部区域
- **用户头像**：圆形，约48-56px，卡通风格
- **用户名**：粗体，约18sp
- **功能图标**：搜索、通知、设置，约24px，线性样式

#### 列表分组
1. **系统预设组**（无分隔线）
   - 今天（橙色数字图标）
   - 收集箱（橙色T图标）
   - 订阅日历（蓝色RSS图标）
   - 标签（蓝色标签图标）

2. **用户自定义组**（与上方有细线分隔）
   - 欢迎（挥手emoji）
   - 工作任务（公文包emoji）← **当前选中**
   - 个人备忘（房屋emoji）
   - 购物清单（包裹emoji）
   - 学习安排（书本emoji）
   - 心愿清单（独角兽emoji）

#### 选中态表现
- **背景**：浅蓝色/浅紫色背景（约#E8F0FE / #F0F4FF）
- **圆角**：约8-12px，与列表项同高
- **文字**：可能略微加粗或变色
- **右侧数量**：灰色数字

#### 底部操作区
- **左侧**："+ 添加"按钮，图标+文字
- **右侧**：筛选/排序图标（三条横线+点）

### 2.3 任务列表项视觉设计

#### 复选框样式
- **形状**：圆形（非方形）
- **尺寸**：约20-24px
- **未完成态**：灰色细边框，内部空白
- **完成态**：
  - 蓝色填充 + 白色对勾
  - 或 灰色填充 + 白色对勾（已完成任务列表中）

#### 任务标题
- **字号**：约16-17sp
- **字重**：Medium (500)
- **颜色**：深灰色/黑色（#333333）

#### 辅助信息排布
- **日期/时间**：任务标题下方或右侧，灰色小字
- **标签**：任务下方，药丸形背景色块
- **清单图标**：左侧，emoji或自定义图标

#### 完成态样式
- **文字**：灰色 + 删除线（或仅变灰）
- **复选框**：填充为灰色/蓝色
- **整体透明度**：可能降低到70-80%

### 2.4 右上角三点菜单

#### 菜单样式
- **背景**：纯白色
- **圆角**：约12-16px
- **阴影**：明显投影，增强悬浮感
- **宽度**：约240-280dp
- **位置**：从右上角向下展开

#### 菜单项构成
1. **编辑**（铅笔图标）
2. **视图**（列表图标 + 右箭头，表示有子菜单）
3. **背景**（图片图标）
4. **显示详细**（列表图标）
5. **隐藏已完成**（复选框图标）
6. **分组排序**（排序图标）
7. **管理分组**（层叠图标）
8. **批量选择**（多选图标）
9. **更多**（三点图标 + 右箭头）

#### 图标风格
- **类型**：线性图标（Outlined）
- **尺寸**：约20-24px
- **颜色**：深灰色（#333333）
- **右侧箭头**：灰色，约16px

### 2.5 浮动操作按钮（FAB）

- **形状**：圆形
- **尺寸**：约56-64dp
- **颜色**：蓝色（#4A90E2）
- **图标**：白色"+"，约24px
- **位置**：右下角，距离边缘约16dp
- **阴影**：明显投影，增强悬浮感

## 3. 添加任务页面分析

### 3.1 表单结构

#### 触发方式
- 点击FAB按钮
- 从底部弹出（Bottom Sheet）

#### 顶部信息栏
- **清单图标**：emoji（公文包）
- **清单名称**：粗体文字
- **下拉箭头**：点击可切换清单
- **右侧图标**：旗帜（优先级）、三点菜单

#### 元数据行
- **左侧**：日历图标 + "日期与提醒"文字
- **右侧**：进度圆环（25%）+ 百分比数字

#### 任务标题输入区
- **字号**：约18-20sp
- **字重**：Bold (700)
- **占位符**：可能为"任务标题"（灰色）
- **边框**：无明显边框，底部可能有细线

#### 子任务区域
- **复选框**：圆形，与主任务一致
- **拖拽图标**：右侧三条横线，用于排序
- **已完成子任务**：灰色 + 删除线
- **新增子任务行**：空白复选框 + 光标闪烁

### 3.2 选项行视觉设计

#### 典型行样式
```
[图标] [文字]                    [右侧值/箭头]
```

#### 日期行
- **图标**：日历（灰色）
- **文字**："日期与提醒"
- **右侧**：无（或点击后展开日期选择器）

#### 优先级行（推测）
- **图标**：旗帜
- **右侧**：颜色标记（红/橙/蓝/无）

#### 标签行
- **图标**：标签
- **右侧**：已选标签列表（药丸形）

#### 清单行
- **图标**：文件夹/公文包
- **右侧**：当前清单名称

### 3.3 日期/优先级/标签/清单的呈现方式

#### 日期选择
- 点击后展开底部日期选择器
- 预设选项：今天、明天、下周、自定义
- 可选时间提醒

#### 优先级
- 4级：红色（高）、橙色（中）、蓝色（低）、无
- 点击循环切换或展开选择

#### 标签
- 药丸形色块
- 支持多选
- 可新建标签

#### 清单切换
- 点击顶部清单名称或下拉箭头
- 弹出"移动到"底部弹窗
- 列出所有清单，当前选中项有蓝色对勾

### 3.4 键盘弹出时的布局适配

#### 观察
- **内容区域**：向上滚动，保持输入框可见
- **底部工具栏**：固定在键盘上方
- **工具栏图标**：标签、列表、闹钟、附件、撤销、重做、收起键盘

#### 工具栏功能
1. **标签**：添加/编辑标签
2. **列表**：添加子任务
3. **闹钟**：设置提醒
4. **附件**：添加文件/图片
5. **撤销/重做**：操作历史
6. **收起键盘**：向下箭头图标

### 3.5 左上角切换任务清单的交互样式

#### "移动到"弹窗
- **触发**：点击任务详情中的清单名称/下拉箭头
- **样式**：底部弹出表单
- **顶部**：X关闭按钮 + "移动到"标题
- **搜索框**：占位符"搜索"，灰色背景
- **清单列表**：
  - 左侧：清单emoji图标
  - 中间：清单名称
  - 右侧：蓝色对勾（当前选中）或右箭头（可展开子清单）
- **底部**："+ 添加清单"（蓝色文字链接）

### 3.6 保存/完成按钮的位置与样式

#### 观察
- **无明显保存按钮**：任务自动保存（失去焦点或返回时保存）
- **完成操作**：
  - 任务列表中的复选框：点击即完成
  - 任务详情底部的完成按钮（推测存在，但截图未显示）
- **关闭/返回**：左上角返回箭头或X按钮

#### 观察
- **截图未显示空状态**

#### 侧边栏
- **分组间**：细线（约1px，#E0E0E0）

## 5. 对本项目（Flutter 待办 App）的借鉴要点

### 5.1 值得直接借鉴的设计元素

#### 1. 侧边栏抽屉模式
- **宽度比例**：75-80%屏幕宽度
- **分组逻辑**：系统预设 + 用户自定义，用分隔线区分
- **选中态**：浅色背景 + 圆角，视觉清晰
- **底部操作**：添加按钮 + 筛选/排序

#### 2. FAB按钮设计
- **圆形 + 蓝色**：经典且醒目
- **位置**：右下角，符合拇指热区
- **阴影**：增强悬浮感和可点击性

#### 3. 任务卡片布局
- **白色背景 + 轻微圆角**：简洁现代
- **时间戳图标**：右上角，不干扰主内容
- **间距节奏**：卡片间有呼吸感

#### 4. 三点菜单设计
- **圆角弹窗**：与整体风格一致
- **线性图标**：简洁统一
- **分组逻辑**：常用操作 + 分隔线 + 更多操作

#### 5. 底部导航栏
- **5个图标**：覆盖主要功能
- **选中态**：填充颜色，未选中为线性
- **高度**：约56dp，标准尺寸

#### 6. 添加任务底部弹窗
- **表单结构**：清单选择 → 元数据 → 标题 → 子任务 → 标签
- **自动保存**：无需显式保存按钮
- **工具栏**：键盘弹出时固定，提供快捷操作

### 5.2 需要结合本项目特点调整的设计元素

#### 1. 平台适配（桌面 + 移动端）
- **侧边栏**：
  - 移动端：抽屉模式
  - 桌面端：永久展开的侧边栏（约300-320dp宽度）
- **FAB按钮**：
  - 移动端：右下角悬浮
  - 桌面端：可集成到顶部栏或侧边栏底部
- **底部导航**：
  - 移动端：固定底部
  - 桌面端：可转为侧边栏图标或顶部标签

#### 2. Material 3 风格适配
- **色彩**：使用Material 3的动态取色（Dynamic Color）
- **圆角**：采用Material 3的大圆角（16-28dp）
- **阴影**：使用Material 3的色调阴影（Tonal Elevation）
- **图标**：使用Material Symbols（可变字重）

#### 3. 多端同步状态显示
- **滴答清单**：无明显同步状态指示
- **本项目建议**：
  - 顶部添加同步状态图标（同步中/已完成/错误）
  - 任务卡片显示最后同步时间

#### 4. 数据模型差异
- **滴答清单**：任务 + 子任务 + 标签 + 清单
- **本项目**：项目 + 任务 + 子任务 + 标签（无清单概念）
- **调整**：
  - 侧边栏显示"项目"而非"清单"
  - 任务详情显示所属项目而非清单

#### 5. 状态管理（派生状态）
- **滴答清单**：任务状态可手动修改
- **本项目约束**：有子任务的任务，状态由子任务派生计算
- **UI体现**：
  - 禁用有子任务任务的复选框直接点击
  - 显示进度百分比（如25%）
  - 状态文字说明"由子任务决定"

#### 6. 删除语义差异
- **滴答清单**：删除 = 彻底删除
- **本项目**：删除 = 本地硬删 + 快照墓碑（同步删除）
- **UI体现**：
  - 删除操作可添加确认对话框
  - 显示"删除后将同步到其他设备"的提示

#### 7. 时间存储方式
- **滴答清单**：可能存储为本地时间
- **本项目**：强制UTC毫秒存储
- **UI体现**：
  - 显示时转换为本地时区
  - 跨时区协作时显示时区信息

### 5.3 本项目独有的设计机会

#### 1. 桌面端增强
- **多列布局**：侧边栏 + 任务列表 + 任务详情（三栏）
- **拖拽排序**：任务在列表间拖拽移动
- **键盘快捷键**：快速添加任务、切换视图

#### 2. 同步状态可视化
- **实时同步指示器**：顶部状态栏显示同步状态
- **冲突解决UI**：当多端编辑冲突时的处理界面
- **离线模式提示**：网络断开时的视觉提示

#### 3. 数据模型一致性
- **派生状态可视化**：有子任务的任务显示进度环
- **状态锁定提示**：禁用直接修改时的视觉反馈
- **层级深度指示**：最多3级任务的视觉层级

#### 4. 安全性UI
- **凭据输入**：同步服务器地址/账号/密钥的安全输入界面
- **加密状态**：显示数据加密状态
- **安全存储提示**：flutter_secure_storage的使用提示
