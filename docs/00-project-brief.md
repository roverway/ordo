# 00 — 项目简报（Project Brief）

> 本文档是项目的总纲。所有后续文档（需求、技术栈、架构、数据模型、UI、同步、里程碑）均以本文档的决策为准。

## 1. 项目概述

一个**跨平台个人待办事项应用**，支持 Windows / Linux / Android / iOS 四个平台（v1 先交付 **Android + Windows**，其余平台后续追加，代码无需分叉）。

- 核心场景：个人任务管理，任务可归属项目、打标签，最多三级层级，支持拖拽调整层级与排序。
- 核心能力：基于 **WebDAV 或 S3 兼容桶**的多端**接力同步**（同一时间只有一台设备在编辑，不做多端同时编辑）。
- 定位：**移动端优先**的界面体验，同时自适应桌面/平板尺寸；支持多语言与明暗主题。

## 2. 目标（Goals）

1. 提供清晰、美观、易用的三级任务管理体验（移动端优先）。
2. 数据完全离线可用（本地 SQLite），同步为后台能力而非前置条件。
3. 通过 WebDAV / S3 实现个人多设备之间的可靠接力同步，数据不丢失。
4. 一套代码覆盖四平台，UI 自适应不同屏幕尺寸。
5. 支持多语言（v1: 简体中文 + 英文）与明/暗/跟随系统主题。

## 3. 非目标（Non-Goals，v1 明确不做）

| 非目标 | 说明 |
|---|---|
| 提醒通知 | 不做本地通知/角标提醒（数据模型预留时间字段，后续可加） |
| 重复任务 | 不做按日/周/月重复规则 |
| 多用户/账号体系 | 纯个人单机单账号，无登录、无注册、无云端用户体系 |
| 多端同时编辑 | 仅接力同步（LWW 合并），不做实时协作/冲突 UI 解决 |
| 富文本/附件 | 描述与备注 v1 为纯文本；图片等附件后续扩展 |
| Web 端 | v1 不发布 Web 版本 |
| 多人共享/协作 | 无 |

## 4. 关键决策表

| 决策点 | 结论 | 依据 |
|---|---|---|
| 框架 | **Flutter 3.x + Dart 3** | 一套代码覆盖 Win/Linux/Android/iOS；移动优先 UI + 自适应能力强；i18n/主题内置成熟 |
| 存储 | **SQLite（Drift）** | 关系型数据（层级/多对多）+ 同步需要逐行 `id/updatedAt/deleted` 追踪，文本文件无法胜任 |
| 状态管理 | **flutter_riverpod**（无 codegen） | 声明式、可测试、与 Drift 流式查询配合好 |
| 路由 | **go_router** | 官方推荐，state-driven，支持自适应导航高亮 |
| UI 风格 | **Material 3 + 自定义设计令牌** | 复现 MIUI 视觉语言（squircle 圆角/弹簧动效/Monet 动态色），但不绑定年轻且不稳定的 `flutter_miuix` 包（见 `20-tech-stack.md` §3） |
| 同步存储 | **WebDAV 与 S3 兼容桶双实现** | 统一 `RemoteStore` 抽象，两套实现 |
| 同步算法 | **单文件 gzip 快照 + 按记录 LWW 合并 + 墓碑** | 个人数据量（<5 万条）下简单、可调试、天然备份；见 `60-sync-design.md` |
| 任务层级 | 项目下最多 **3 级**任务（项目不算级） | 用户确认 |
| 任务状态 | 4 态：`todo / inProgress / done / cancelled` | 用户确认 |
| 父子联动 | 父任务状态/完成度 = **子任务派生计算**，不存冗余 | 用户确认（Oracle 评审要求 M1 前定稿） |
| 账号 | 无登录体系；同步仅填服务器地址+密钥 | 用户确认 |
| 平台优先级 | v1: **Android + Windows**；iOS/Linux 后置 | 用户确认 |
| 凭据存储 | `flutter_secure_storage`（Android Keystore / Windows DPAPI） | Oracle 评审 H1 |
| 语言 | v1: `zh-CN` + `en-US` | 默认假设 |

## 5. 术语表

| 术语 | 含义 |
|---|---|
| 任务（Task） | 最小工作单元，可含子任务，最多 3 级 |
| 项目（Project） | 任务的容器，一对多 |
| 标签（Tag） | 跨项目对任务分类，多对多 |
| 墓碑（Tombstone） | 记录被删除的标记（`deleted=true`），用于同步传播删除 |
| 接力同步 | 同一时刻仅一台设备编辑，通过快照合并把改动带到其他设备 |
| LWW | Last-Write-Wins，按 `updatedAt` 取较新者 |
| 派生状态 | 有子任务的任务，其状态由子任务计算得出，不存储 |
| 设计令牌（Token） | 颜色/圆角/间距/动效等设计变量的具名常量 |
