## 1. 参考案例拆解

### 1.1 简约模式（`任务清单-简约模式.jpg`）

**整体结构**：
- 页面标题「收集箱」+ 搜索/更多操作图标（AppBar）
- 任务按「事项」分组（事项 2、事项 1），每组是一个圆角卡片容器
- 卡片内是扁平的任务行，无独立卡片底色
- 右下角蓝色圆形 FAB（+号）
- 底部 5 个 tab 的导航栏

**任务行特征**：
- **勾选框**：方形（□），非圆形；一级任务为蓝色边框，子任务为红色边框（按层级着色）
- **标题**：单行，左对齐，字号适中（约 16sp）
- **元信息**：行内小图标（标签🏷️、位置📍），紧贴标题右侧，不换行
- **子任务数 + 展开箭头**：行尾右侧显示数字（如 `1 ^`、`2 ▲`），点击展开/折叠
- **日期范围**：展开后在子任务下方显示（如「8月25日～8月27日 距开始12天」），橙色文字
- **层级缩进**：通过左侧 padding 递进缩进，无竖线引导
- **分隔**：同组内任务行之间无分隔线，组与组之间有明显间距

**视觉语言**：
- 背景：浅灰底（#F2F4F7 级别）
- 卡片：白色圆角容器（约 12-16px 圆角），无阴影或极轻阴影
- 行高：宽松，约 48-56dp
- 颜色：克制，仅勾选框/日期/少数图标有颜色，其余为黑灰

### 1.2 详细模式（`任务清单-详细模式.jpg`）

**整体结构**：
- 与简约模式相同的分组卡片结构
- 每个任务行下方展开更多信息

**任务行特征（相比简约模式新增）**：
- **描述文字**：标题下方显示任务描述（灰色，约 12-13sp）
- **位置信息**：带 📍 图标 + 地址文字（如「松榆西里社区」）
- **标签 chips**：彩色圆角药丸（tag1 黄底、tag2 绿底、tag3 蓝底、tag4 绿底），内联在描述下方
- **日期范围**：同样显示，但增加了「下周一」这样的相对时间提示
- **子任务数 + 展开箭头**：同简约模式

**视觉语言**：
- 信息密度更高，但通过字号/颜色区分层级
- 描述文字用浅灰色，与标题形成主次对比
- 标签 chips 用低饱和度背景色 + 深色文字，不抢视觉焦点

### 1.3 共同设计语言总结

| 维度 | 参考案例特征 |
|---|---|
| **布局模式** | 扁平行式（非卡片行），任务行无独立卡片底/阴影 |
| **分组方式** | 按项目/事项分组，每组一个圆角容器卡片 |
| **勾选框** | 方形，按层级着色（一级蓝、子级红） |
| **层级表达** | 纯缩进（padding-left 递进），无竖线 |
| **子任务信息** | 行尾显示子任务数量 + 展开/折叠箭头 |
| **日期呈现** | 日期范围 + 相对时间（距开始X天），橙色强调 |
| **标签** | 彩色圆角药丸 chips，内联在描述下方 |
| **描述** | 标题下方灰色小字，可选显示 |
| **间距节奏** | 宽松行高（48-56dp），组间间距大，组内行间距适中 |
| **颜色使用** | 克制，仅勾选框/日期/标签有颜色，整体素雅 |

## 2. 现状问题诊断

对比参考案例，当前实现（`TaskRow` + `TaskTree`）存在以下差距：

### 2.1 布局模式差异

| 维度 | 参考案例 | 当前实现 | 差距 |
|---|---|---|---|
| **任务行形态** | 扁平行（无卡片底） | 卡片行（白底 + 圆角 + 阴影） | 视觉层级过重，卡片感过强 |
| **分组方式** | 按项目分组，组=卡片容器 | 一级任务=卡片，子任务=卡片内行 | 一级任务各自成卡，碎片化 |
| **整体密度** | 宽松、留白充足 | 紧凑（compact 模式行高压缩） | 当前偏挤，参考更舒展 |

### 2.2 勾选框差异

| 维度 | 参考案例 | 当前实现 | 差距 |
|---|---|---|---|
| **形状** | 方形（□） | 圆形（○，TickTick 风格） | 风格不一致 |
| **层级着色** | 一级蓝、子级红 | 统一蓝色（完成态） | 缺少层级视觉区分 |

### 2.3 信息呈现差异

| 维度 | 参考案例 | 当前实现 | 差距 |
|---|---|---|---|
| **子任务数** | 行尾显示数字 + 箭头 | 仅展开箭头，无数字 | 用户无法一眼看到子任务数量 |
| **日期范围** | 显眼的日期范围 + 相对时间 | 行尾小图标 + 短日期 | 日期信息不够突出 |
| **描述文字** | 标题下方灰色小字 | 无（需进编辑页才看到） | 列表页信息量不足 |
| **标签位置** | 描述下方，独立一行 | 标题同行内联 | 标签与标题挤在一起 |

### 2.4 层级表达差异

| 维度 | 参考案例 | 当前实现 | 差距 |
|---|---|---|---|
| **缩进方式** | 纯 padding 缩进 | padding + 展开箭头前置 | 箭头在最左侧，缩进感弱 |
| **视觉引导** | 无竖线，靠缩进 | 无竖线（一致） | — |

### 2.5 交互差异

| 维度 | 参考案例 | 当前实现 | 差距 |
|---|---|---|---|
| **展开/折叠** | 行尾箭头 + 数字 | 行首箭头 | 操作位置不同 |
| **拖拽** | 未明确显示 | 长按拖拽（完整保留） | 当前更丰富 |
| **菜单** | 行尾「⋯」图标 | 行尾「⋮」图标 | 一致 |

## 3. 设计方向

### 3.1 整体设计语言定义

**核心决策：从「卡片行」回归「扁平行 + 分组卡片容器」**

- 保留 `TaskTree` 的分组结构（一级任务 = 分组容器），但**任务行本身不再有独立卡片底/阴影**
- 分组容器（一级任务卡片）保留白底 + 圆角 + 轻阴影，作为视觉锚点
- 子任务行回归扁平行（Divider 分隔），与参考案例对齐
- **今日/收件箱作用域**也统一为扁平行式（`SimpleTaskTile` 同步改造）

**视觉基调**：
- 背景：`surfacePageLight`（浅灰 #F2F4F7）
- 分组容器：`surfaceCard`（白）+ `radiusCard`（16）+ 轻阴影
- 任务行：透明底，无阴影，Divider 分隔
- 颜色：克制使用，仅勾选框/日期/标签/状态有颜色

### 3.2 间距节奏

- **行高**：一级任务行 56dp，子任务行 48dp（从当前 compact 的 ~40dp 放松）
- **组内行间距**：8dp（当前 Divider height: 1 保持，但增加上下 padding）
- **组间间距**：16dp（当前 `spaceSm` 保持）
- **左右 padding**：16dp（`spaceMd`）

### 3.3 视觉层级

```
页面背景（浅灰）
 └─ 分组容器（白卡，圆角 16，轻阴影）
     ├─ 一级任务行（56dp 高，勾选 + 标题 + 元信息 + 子任务数 + 展开箭头 + 菜单）
     ├─ Divider
     ├─ 二级任务行（48dp 高，缩进 24dp）
     │   ├─ Divider
     │   └─ 三级任务行（48dp 高，缩进 48dp）
     └─ Divider
```

## 4. 分元素详细规格

### 4.1 任务行布局

**一级任务行（分组容器头部）**：

```
┌──────────────────────────────────────────────────────────┐
│ [缩进0] [□] [标题] [标签chips] [Spacer] [子任务数] [>] [⋮] │
│         [描述文字（可选）]                                   │
│         [日期范围 + 相对时间（可选）]                         │
└──────────────────────────────────────────────────────────┘
```

- 高度：56dp（含上下 padding 各 8dp）
- 左 padding：`spaceMd`（16dp）
- 右 padding：`spaceXs`（8dp，菜单按钮区域）
- 勾选框与标题间距：`spaceXs`（8dp）
- 标题与菜单之间：Spacer 撑开
- 描述/日期：标题下方，左对齐与标题齐平

**子任务行（compact 变体）**：

```
┌──────────────────────────────────────────────────────────┐
│ [缩进N] [□] [标题] [标签chips] [Spacer] [子任务数] [>] [⋮] │
│         [描述文字（可选）]                                   │
│         [日期范围 + 相对时间（可选）]                         │
└──────────────────────────────────────────────────────────┘
```

- 高度：48dp（含上下 padding 各 6dp）
- 左 padding：`spaceMd` + `depth × 24dp`（缩进值见 §4.3）
- 其余同一级行

### 4.2 勾选框样式

**形状**：方形（`RoundedRectangleBorder`，圆角 4dp）

**尺寸**：24dp × 24dp（`AppTokens.checkboxSize` 保持）

**状态样式**：

| 状态 | 边框 | 填充 | 图标 |
|---|---|---|---|
| 未完成（一级） | `colorInProgress`（蓝 #4A6CF7），1.5dp | 透明 | 无 |
| 未完成（子级） | `colorPriorityHigh`（红 #EF6B6B），1.5dp | 透明 | 无 |
| 已完成 | `colorInProgress`（蓝），1.5dp | `colorInProgress` 填充 | 白色 ✓ |
| 禁用（有子任务，派生） | `onSurfaceVariant` 30% 透明度 | `onSurfaceVariant` 15% 透明度 | 无 |

**新增令牌**：
```dart
// AppTokens 新增
static const double checkboxRadius = 4;        // 方形勾选框圆角
static const OutlinedBorder checkboxShapeSquare = RoundedRectangleBorder(
  borderRadius: BorderRadius.circular(4),
);
```

### 4.3 层级缩进

| 深度 | 缩进值 | 说明 |
|---|---|---|
| 0（一级） | 0dp | 无缩进，对齐卡片左边缘 |
| 1（二级） | 24dp | 从卡片左 padding 起算 |
| 2（三级） | 48dp | 二级再缩进 24dp |

**引导方式**：纯缩进，无竖线（与参考案例一致）

**新增令牌**：
```dart
// AppTokens 新增
static const double treeIndentLevel = 24;  // 每级缩进量（替代 treeIndent=28）
```

### 4.4 优先级/截止日期/标签/进度的呈现

**优先级**：
- 不在任务行直接显示旗帜图标（参考案例未显示）
- 保持现有逻辑：优先级在编辑页/拖拽菜单中操作
- 高优先级任务标题可加粗或左侧加 3dp 色条（可选，参考案例未明确）

**截止日期**：
- **位置**：标题下方独立行（从当前的行尾内联改为下方展示）
- **格式**：「8月25日～8月27日 距开始12天」（日期范围 + 相对时间）
- **颜色**：橙色（`colorPriorityMedium` #F4A74A）用于「距开始X天」；灰色用于日期范围
- **字号**：`textCaptionSize`（12sp）
- **新增令牌**：
```dart
// AppTokens 新增
static const Color colorDateRelative = Color(0xFFF4A74A);  // 相对时间（距开始X天）
```

**标签 chips**：
- **位置**：描述文字下方（从当前的标题同行改为下方独立行）
- **样式**：保持现有 chip 样式（`radiusChip` 10，低饱和度背景 + 深色文字）
- **数量**：最多显示 2 个 + 「+N」（保持现有逻辑）

**进度环**：
- **位置**：行尾，子任务数左侧（保持现有位置）
- **样式**：保持现有 `TaskProgressRing`（`progressRingSize` 24）

### 4.5 展开/折叠控件与动画

**控件位置**：行尾，菜单按钮左侧（从当前的行首改为行尾，与参考案例对齐）

**控件组成**：子任务数量文字 + 展开/折叠箭头

```
[2 ▲]  ← 展开态（显示子任务数 2，箭头朝上）
[2 ▼]  ← 折叠态（显示子任务数 2，箭头朝下）
```

**无子任务时**：不显示数量和箭头

**动画**：
- 箭头旋转：`AnimatedRotation`，150ms（`motionFast`），`Curves.easeOutCubic`
- 展开区高度动画：`AnimatedSize`，250ms（`motionNormal`），`Curves.easeOutCubic`

**新增令牌**：
```dart
// AppTokens 新增
static const double expandArrowSizeRow = 16;  // 行内展开箭头（比当前 20 稍小）
```

### 4.6 拖拽把手与拖拽态视觉

**拖拽触发**：长按任务行（保持现有 `LongPressDraggable`）

**拖拽态视觉**：
- 拖拽中：原行 `Opacity(0.3)`（保持现有）
- 反馈物：半透明卡片 + 阴影（保持现有）
- 目标行高亮：蓝色边框 2dp（保持现有）
- 非法目标：红色边框 2dp + 红色背景 40%（保持现有）

**拖拽到子级指示**：行尾显示 `subdirectory_arrow_right` 图标（保持现有）

### 4.7 hover/按压/选中态

| 状态 | 视觉反馈 |
|---|---|
| **hover**（桌面） | 行背景变为 `surfaceContainerHighest` 40% 透明度（保持现有） |
| **按压** | InkWell 涟漪效果（保持现有） |
| **选中**（无明确选中态） | — |
| **拖拽悬停** | 蓝色边框 + 浅蓝背景（保持现有） |

### 4.8 空状态

保持现有 `EmptyState` 组件（图标 + 文案 + 操作按钮），不改动。

### 4.9 简约模式/详细模式映射

**建议：不提供两档显示密度切换**

理由：
1. 参考案例的「简约/详细」差异主要在于描述文字和标签是否展开，而非行高/密度的根本变化
2. 当前项目数据模型中，描述字段已是可选（可为空），空描述时自动呈现简约效果
3. 增加模式切换增加 UI 复杂度，与 v1 范围不符

**折中方案**：
- 有描述的任务：显示描述文字（详细效果）
- 无描述的任务：不显示描述行（简约效果）
- 标签 chips 始终显示（有标签时）
- 日期范围始终显示（有日期时）

这自然形成了「有信息则详细，无信息则简约」的效果，无需显式模式切换。

## 5. 实现约束提醒

### 5.1 设计令牌

- **所有颜色**：必须使用 `AppTokens` 中定义的令牌，禁止硬编码 `Color(0x...)`
- **所有圆角**：必须使用 `AppTokens.radiusCard` / `radiusList` / `radiusChip` 等
- **所有间距**：必须使用 `AppTokens.spaceXxs` / `spaceXs` / `spaceSm` / `spaceMd` 等
- **新增令牌**：必须在 `AppTokens` 中声明，附注释说明用途

### 5.2 国际化

- 所有用户可见文案必须走 ARB（`lib/core/l10n/app_localizations.dart`）
- 新增文案（如「距开始X天」的格式化）需在 ARB 中定义
- 改 ARB 后运行 `flutter gen-l10n`

### 5.3 既有交互保留

- **拖拽排序/调级**：`TaskTree` 的 `LongPressDraggable` + `DragTarget` 逻辑完整保留
- **深度校验**：`_fitsDepthLimit` 防环/超深逻辑不变
- **菜单操作**：编辑/新建子任务/上移/下移/缩进/缩出/删除全部保留
- **展开/折叠状态**：`treeExpandProvider` 状态管理不变

### 5.4 测试

- 改造后 `flutter analyze` 必须 0 error
- `flutter test` 全绿
- `widget_test.dart` 中任务行相关断言需更新（方形勾选框、行尾展开箭头等）

## 6. 分阶段改造建议

### 阶段 1：快速见效（1-2 天）

**目标**：任务行从「卡片行」改为「扁平行」，视觉立即清爽

**改动范围**：
1. `TaskRow` 移除卡片底色/阴影（`_cardColor` 返回透明；`AnimatedContainer` 的 `BoxDecoration` 移除 `boxShadow`）
2. `TaskRow` 勾选框改为方形（`AppTokens.checkboxShapeSquare`）
3. `TaskTree` 一级卡片保留白底 + 圆角 + 阴影（作为分组容器）
4. 子任务行间距从 `spaceXxs` 放松到 `spaceXs`（行高 40→48dp）

**预期效果**：一级卡片作为视觉锚点，子任务行回归扁平，整体层次更清晰

### 阶段 2：信息层级优化（2-3 天）

**目标**：日期/描述/标签的呈现方式与参考案例对齐

**改动范围**：
1. 日期从行尾内联改为标题下方独立行（新增日期行 Widget）
2. 标签 chips 从标题同行改为描述下方独立行
3. 描述文字默认显示（有内容时）
4. 子任务数 + 展开箭头从行首移到行尾

**预期效果**：信息层级更清晰，日期/标签更醒目

### 阶段 3：细节打磨（1-2 天）

**目标**：动效、hover 态、空状态等细节完善

**改动范围**：
1. 展开/折叠动画（`AnimatedSize` 包裹展开区）
2. hover 态背景色过渡动画
3. 今日/收件箱作用域的 `SimpleTaskTile` 同步改造（扁平行 + 方形勾选框）
4. 空状态图标/文案微调

**预期效果**：交互体验完整，动效流畅

### 阶段 4：可选增强（后续）

**目标**：参考案例中「距开始X天」等相对时间显示

**改动范围**：
1. 新增日期格式化函数（支持「距开始X天」「下周X」等相对时间）
2. 新增 `colorDateRelative` 令牌
3. 日期行显示相对时间（有开始日期时）

**预期效果**：日期信息更实用，与参考案例完全对齐
