### 2.2 协议一致性与边界加固清单

1. **协议协商 (`initialize`)**:
   - 协商并返回双方支持的最佳协议版本（兼容 `2024-11-05` 与 `2025-03-26`）。
2. **JSON-RPC 严格类型检查**:
   - `tools/call` 的 `params['name']` 必须为 String，非法类型返回 `-32602 Invalid params`。
   - JSON-RPC 批处理调用：空批处理请求返回 `-32600 Invalid Request`；单条非对象元素单独返回 `-32600`。
3. **Notification 处理**:
   - 纯通知请求（无 `id`）由服务端返回 HTTP 202 快速接受，符合标准 RPC 规范。

### 2.3 工具集增强与高杠杆新增

1. **`query_tasks` 返回字段补齐**:
   - 补充 `notes`, `updatedAt`, `sortOrder`, `dueAt`, `startAt`，保留 `description` 兼容性。
2. **`update_task` 完整变更集 (Diff)**:
   - 返回 `updatedFields`、`previousValues` 和 `currentValues`，让模型清晰掌握每次修改的前后状态对比。
3. **`delete_tasks` 预解析能力**:
   - 删除前反查任务标题与统计，返回已删除任务详情与不存在的任务 ID。
4. **新增 `daily_briefing` 工具**:
   - 一次调用聚合：已逾期待办、今日到期、进行中、今日与昨日已完成数、四象限高优先级未完结任务及项目分布。
5. **新增 `manage_tags` 工具**:
   - 支持标签的列表查询 (`list`)、创建 (`create`，支持 hex 颜色)、删除 (`delete`) 与重命名 (`rename`)。
   - 工具总数扩充至 **13** 个标准工具。
