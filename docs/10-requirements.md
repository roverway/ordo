# 10 — 需求规格（Requirements）

> 编号规则：`FR-<模块>-<序号>`（功能需求）、`NFR-<序号>`（非功能需求）。每个 FR 后附验收标准（AC）。本文档是开发与验收的唯一依据。

## 1. 功能需求总览

| 模块 | 编号段 | 说明 |
|---|---|---|
| 导航与布局 | FR-NAV | 自适应导航、视图切换 |
| 项目 | FR-PRJ | 项目 CRUD、颜色、排序 |
| 文件夹 | FR-FLD | 文件夹收纳项目、展开/折叠、拖拽排序（`62-folder-nav.md`） |
| 任务 | FR-TSK | 三级任务 CRUD、字段、状态、拖拽 |
| 标签 | FR-TAG | 标签 CRUD、多对多关联 |
| 视图 | FR-VIEW | 今日/日历/项目/标签/搜索/筛选 |
| 同步 | FR-SYNC | WebDAV/S3 配置、触发、状态展示 |
| 设置 | FR-SET | 主题、语言、同步设置 |
| 国际化与主题 | FR-L10N / FR-THM | 多语言、明暗主题 |

## 2. 导航与布局（FR-NAV）

- **FR-NAV-01** 自适应导航：窄屏（<600dp）用**侧边栏抽屉**承载清单导航（系统组：今日/收集箱/日历/标签；项目区：**文件夹组（各含项目行）+ 未分组区** + 未完成数；底部「新建项目」「新建文件夹」），AppBar 汉堡打开；宽屏（≥600dp）用左侧 NavigationRail（收集箱/今日/日历/项目/标签，5 目的地不变）。窄屏底部为**精简紧凑底栏（自绘，高 56dp）**，2 个系统入口：**今日、日历**（标签移入抽屉，`57-task-page-polish.md` §4.1 D5）。
  - AC：窄屏点击汉堡打开抽屉，当前项浅色药丸高亮；点击系统项/项目跳转对应路由并关闭抽屉；遮罩点击可关闭。
  - AC：抽屉项目区 = 文件夹展开/折叠 + 项目行缩进；未分组区在文件夹之后（收件箱仍由系统组承载）。
  - AC：底栏用列表渲染（可扩展），非底栏路径（收件箱/项目/搜索/设置）视觉**无选中**（自绘 `CompactBottomBar`，`selectedIndex = -1`）。
  - AC：宽屏 Rail 5 目的地与窄屏抽屉入口并存，路由不变（`/inbox /today /calendar /projects /tags`）。
  - AC：**今日 / 收件箱 / 项目三个任务类入口统一渲染为 `TaskListPage`（作用域驱动，56-task-scope-page.md §3）**，均处于 AppShell 壳内（汉堡/底栏/Rail 常驻）；启动默认页为 `/today`（D3）。
- **FR-NAV-02** 搜索与设置入口位于 AppBar（图标按钮），所有视图可用。
  - AC：任意视图点击搜索/设置图标可进入对应页。
- **FR-NAV-03** 宽屏采用 master-detail 两栏布局：左栏列表，右栏详情/编辑。
  - AC：≥600dp 时选中列表项，右栏展示详情；窄屏则推入新页面。
- **FR-NAV-04** 路由集中管理，支持深链参数（项目 id、日期等）。
  - AC：`go_router` 路由表唯一，页面不自行管理导航栈。

## 3. 项目（FR-PRJ）

- **FR-PRJ-01** 项目 CRUD：创建、重命名、改颜色、删除、排序。
  - AC：项目列表按 `sortOrder` 显示；删除项目弹确认框。
- **FR-PRJ-02** 项目字段：名称（必填，1–100 字符）、颜色（ARGB）、描述（可选，纯文本）。
  - AC：名称为空时禁止保存并提示。
- **FR-PRJ-03** 删除项目 = 级联删除其下所有任务（含子任务），并产生墓碑。
  - AC：删除后项目及其任务在本地不可见；同步后其他设备同样不可见。
- **FR-PRJ-04** 项目视图展示项目内任务树（最多 3 级），支持展开/折叠。
  - AC：折叠父任务时其子任务隐藏；展开恢复。

## 3.1 文件夹（FR-FLD，`62-folder-nav.md`）

- **FR-FLD-01** 文件夹 CRUD：创建、重命名、删除（单层结构，不嵌套）。
  - AC：名称 1–50 字符，空名/超长拒绝；删除文件夹 = **仅解除收纳**（其中项目回未分组，不级联删项目），确认框明示。
- **FR-FLD-02** 文件夹收纳项目：项目可挂到某文件夹下（`projects.folderId`），或处于未分组。
  - AC：抽屉项目区 = 文件夹组（各含项目行）+ 未分组区（在文件夹之后）；收件箱不参与文件夹。
- **FR-FLD-03** 文件夹展开/折叠：树状显示/隐藏内部项目。
  - AC：点击文件夹行切换展开/折叠；展开状态设备本地持久化（settings，不同步）。
- **FR-FLD-04** 拖拽调整所属文件夹：长按项目行拖到文件夹行 = 入夹；拖到未分组区 = 出夹；同组内拖动 = 组内排序。
  - AC：移动后新旧两组 `sortOrder` 连续（0..n-1）；折叠文件夹作为拖放目标时自动展开。
- **FR-FLD-05** 拖拽文件夹排序：长按文件夹行拖动调整文件夹间顺序。
  - AC：移动后文件夹 `sortOrder` 连续；点击 vs 长按无冲突（长按起拖，点击跳转）。
- **FR-FLD-06** 文件夹参与同步（快照 schemaVersion 1→2）。
  - AC：文件夹增删改/项目移动跨端传播；一端删除文件夹后他端项目归属修复（`reconcileFolderIds`）；旧 v1 快照可兼容读。
- **FR-FLD-07** 宽屏 `/projects` 页按文件夹分组展示（不做拖拽）。
  - AC：分组头 + 项目卡片 + 未分组区，与抽屉分组一致。

## 4. 任务（FR-TSK）

- **FR-TSK-01** 任务 CRUD：创建、编辑、删除、移动。
  - AC：任务可创建于项目下（1 级）、或任意任务下（2/3 级）。
- **FR-TSK-02** 任务字段：标题（必填，1–200 字符）、描述（可选纯文本）、备注（可选纯文本）、开始时间（可选）、结束时间（可选）、状态（4 态）、优先级（4 档：无/低/中/高）、标签（多选）。
  - AC：标题为空禁止保存；描述与备注可多行；优先级为任务自带属性，与状态正交，有子任务的任务同样可设置。
- **FR-TSK-03** 层级上限：项目下最多 3 级任务（项目 > 任务 > 子任务 > 孙任务）。
  - AC：尝试在第 3 级任务下创建子任务被拒绝并提示「最多三级」。
- **FR-TSK-04** 状态机：`todo(0) / inProgress(1) / done(2) / cancelled(3)`。
  - AC：无子任务的任务状态可手动切换；有子任务的任务状态由派生计算（见 §8），状态控件禁用。
- **FR-TSK-05** 起止时间：`startAt`（开始）与 `endAt`（截止）均可选；两者都设置时须 `endAt >= startAt`。
  - AC：违反时禁止保存并提示。
- **FR-TSK-06** 拖拽排序：同级任务可长按拖动调整顺序。
  - AC：拖动后 `sortOrder` 更新，同级内顺序正确。
- **FR-TSK-07** 拖拽调级：任务可拖到另一任务下成为其子级，或拖到项目下回到 1 级。
  - AC：目标为自身或自身后代时拒绝（防环）；目标层级导致子树深度 >3 时拒绝（见 `40-data-model.md` §5）。
- **FR-TSK-08** 拖拽键盘兜底：任务行菜单提供「上移/下移/缩进/缩出」按钮（桌面键盘可达）。
  - AC：按钮与拖拽产生相同结果，且同样执行深度/防环校验。
- **FR-TSK-09** 删除任务 = 级联删除其所有后代 + 墓碑。
  - AC：删除后子树不可见；同步后其他设备同样不可见。
- **FR-TSK-10** 完成联动：父任务状态/完成度由子任务派生（见 §8）。
  - AC：子任务全部完成 → 父任务显示完成；任一子任务进行中 → 父任务显示进行中。

## 5. 标签（FR-TAG）

- **FR-TAG-01** 标签 CRUD：创建、重命名、改颜色、删除。
  - AC：标签名不区分大小写唯一（如 `work` 与 `Work` 视为同一标签）。
- **FR-TAG-02** 任务与标签多对多：一个任务可打多个标签，一个标签可挂多个任务。
  - AC：任务编辑页可增删标签；标签视图列出该标签下所有任务。
- **FR-TAG-03** 删除标签 = 从所有任务移除该标签引用（级联解除），不删除任务。
  - AC：删除后任务仍存在，仅失去该标签。
- **FR-TAG-04** 合并后清理悬空引用：同步合并后，任务中指向不存在/已删除标签的引用被清除。
  - AC：见 `60-sync-design.md` §7 的 reconciliation 规则。

## 6. 视图（FR-VIEW）

- **FR-VIEW-01 今日视图**：列出「今天要做」的任务（匹配规则见 §9）。启动默认页为 `/today`（D3）。
  - AC：按匹配规则精确列出；过期未完成的任务以「逾期」样式标红；今日/收件箱/项目统一渲染于 `TaskListPage`（作用域驱动，56-task-scope-page.md §3）。
- **FR-VIEW-02 日历视图**：周/月两种粒度，按任务起止时间在对应日期格显示任务。
  - AC：跨多天的任务在区间内每天显示；仅截止日的任务显示在截止日；点击日期格可新建/查看该日任务。
- **FR-VIEW-03 项目视图**：项目列表 + 项目详情（任务树）。
  - AC：见 FR-PRJ-04；项目详情 = `TaskListPage` 项目作用域（AppShell 壳内，汉堡/底栏常驻；AppBar 提供编辑/删除；新建走滴答式弹窗）。
- **FR-VIEW-04 标签视图**：标签云/列表，点击进入该标签的任务列表。
  - AC：标签列表按名称排序；任务列表支持按状态筛选。
- **FR-VIEW-05 搜索**：按标题/描述/备注全文搜索（LIKE 匹配，v1 不做中文分词）。
  - AC：输入即搜（防抖 300ms）；结果按最近更新排序。
- **FR-VIEW-06 筛选**：任务列表支持按状态（含「全部」）、标签、时间段筛选。
  - AC：多条件可叠加；筛选条件在视图内持久（会话内）。

## 7. 同步（FR-SYNC）

- **FR-SYNC-01** 支持 WebDAV 与 S3 兼容桶两种远端，二选一启用。
  - AC：设置页可配置并「测试连接」。
- **FR-SYNC-02** 同步触发：手动按钮 + 启动时自动（可关）+ 编辑后防抖 2s 自动（可关）。
  - AC：三种触发均可用；自动触发可独立开关。
- **FR-SYNC-03** 首次同步四分支：本地空+远端有=下载；本地有+远端空=上传；都有=合并；schemaVersion 不匹配=拒绝并警告。
  - AC：四种场景行为符合预期（见 `60-sync-design.md` §5）。
- **FR-SYNC-04** 同步状态可见：显示上次同步时间、进行中/成功/失败状态、错误信息。
  - AC：失败不破坏本地数据；错误信息用户可见且可重试。
- **FR-SYNC-05** 凭据安全：服务器地址/账号/密钥存 `flutter_secure_storage`，不落日志。
  - AC：重启后凭据仍在；日志无明文密钥。
- **FR-SYNC-06** 时钟偏差检测：合并时若远端 `exportedAt` 与本地相差 >5 分钟，提示用户校准时钟。
  - AC：偏差超限时给出警告，不静默合并。
- **FR-SYNC-07** 上传优化：内容无变化跳过上传；快照 gzip 压缩；可选「仅 WiFi 自动同步」。
  - AC：无改动时触发同步不产生上传流量。

## 8. 派生状态规则（FR-TSK-10 细化）

> 定稿于 M1 数据层之前（Oracle 评审 H6）。**禁止**在 DB 中存储父任务的冗余状态字段。

- **8.1 状态派生**（基于直接子任务，排除已删除）：
  - 无子任务 → 使用任务自身手动状态。
  - 全部子任务 `done` → 父任务 `done`。
  - 任一子任务 `inProgress` → 父任务 `inProgress`。
  - 全部子任务 `cancelled` → 父任务 `cancelled`。
  - 其余 → 父任务 `todo`。
- **8.2 完成度**（基于整棵子树，排除 `cancelled` 与已删除）：
  - `progress = done 数量 / 总数量`，无任务时为 0。
- **8.3 UI 约束**：有子任务的任务，状态控件禁用并显示派生徽标；完成度以进度条/百分比展示。

## 9. 时间匹配规则（FR-VIEW-01/02 细化）

- **9.1 今日视图匹配**（本地时区「今天」）：
  - 任务满足任一条件即入选：`startAt` 在今天；`endAt` 在今天；`startAt <= 今天结束 <= endAt`（跨天区间覆盖今天）。
  - 无时间任务不入选今日视图（可在项目/搜索中查看）。
- **9.2 日历视图匹配**：
  - 有区间（startAt+endAt）→ 区间内每天显示。
  - 仅 endAt → 截止日显示。
  - 仅 startAt → 开始日显示。
- **9.3 逾期**：`endAt < 今天开始` 且状态非 `done/cancelled` → 标为逾期。

## 10. 设置（FR-SET）

- **FR-SET-01** 主题设置：跟随系统 / 浅色 / 深色。
  - AC：切换即时生效并持久化。
- **FR-SET-02** 语言设置：简体中文 / English（跟随系统可选）。
  - AC：切换即时生效并持久化；所有文案走 ARB。
- **FR-SET-03** 同步设置：类型（WebDAV/S3）、连接参数、自动同步开关、WiFi-only、立即同步按钮、测试连接。
  - AC：见 FR-SYNC-01/02/07。

## 11. 非功能需求（NFR）

| 编号 | 需求 | 验收标准 |
|---|---|---|
| NFR-01 | 离线优先 | 无网络时全部本地功能可用；同步失败不影响使用 |
| NFR-02 | 性能 | 5 万条任务规模下，列表滚动流畅（流式查询+分页）；快照解析在 isolate 中执行，不阻塞 UI |
| NFR-03 | 可靠性 | 同步失败不损坏本地库；合并为纯函数可单测；迁移有测试 |
| NFR-04 | 安全 | 凭据仅存 secure storage；日志无敏感信息 |
| NFR-05 | 国际化 | 全部用户可见文案走 ARB；无硬编码字符串 |
| NFR-06 | 无障碍 | 触控目标 ≥48dp；关键操作有语义标签；拖拽有键盘兜底 |
| NFR-07 | 可维护性 | `flutter analyze` 0 error；`flutter test` 全绿；`dart format` 通过 |
| NFR-08 | 版本稳定 | 依赖版本锁定，未经用户同意不升级 |
| NFR-09 | 数据安全 | 删除=墓碑语义；墓碑 >90 天可清理（见 `60-sync-design.md` §8） |

## 12. 验收总则

- 每个里程碑按 `70-milestones.md` 的 DoD 逐条自检。
- 提交前必须：`flutter analyze` 0 error、`flutter test` 全绿、`dart format`。
- 功能验收以本文档 AC 为准，AC 未覆盖的行为视为未定义，需先补需求再实现。
