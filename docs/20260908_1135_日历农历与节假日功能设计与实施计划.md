## 6. 验收标准与交付物

1. **核心算法**：1900–2200 年公农历换算准确无误，春节、中秋、清明、端午、除夕等节日准确识别；二十四节气误差在 0 天之内。
2. **调休标注**：2020–2027 年法定节假日标“休”，调休上班日标“班”，架构具备后续增量加载能力。
3. **UI 体验**：月视图和周视图下，日期格子在各屏幕尺寸下文字不挤压、不截断、不溢出；浅色/深色主题均具有高可读性。
4. **设置持久化**：用户关闭农历或关闭调休后，日历格子恢复纯公历展示，应用重启后设置依然保持。
5. **代码质量**：通过所有静态检查与单元测试，零多余依赖。
