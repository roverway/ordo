# 59 — 任务编辑界面优化（定稿）

> 状态：**FINAL — 已与用户讨论定稿（2026-08-12）**。依据：`/home/rw/Downloads/参考2/` 两张 TickTick 任务编辑截图（弹出式 + 全屏）× @designer 逐屏分析 × 当前实现 × 项目约束 × 用户决策（D1–D9）。
> 本文档是实施唯一依据；改代码前同步 `50-ui-ux.md` / `10-requirements.md` / `70-milestones.md`。

## 1. 背景与目标

用户提供两张 TickTick 任务编辑页面截图（弹出式 + 全屏），要求参考优化本项目任务编辑界面。经讨论定稿：**统一编辑器 + 设置项移入底部工具栏**。

## 2. 参考图还原（designer 逐屏分析）

### 2.1 核心结论：同一编辑器，两种容器

弹出式与全屏式**内容区完全相同**（字段顺序、控件、图标、底部工具栏），仅呈现容器不同：

| 维度 | 弹出式 | 全屏式 |
|---|---|---|
| 承载 | 底部上滑半屏弹窗（60–65% 高，顶部圆角 16–20px，遮罩） | 标准全屏页（AppBar + 返回箭头） |
| 用途 | 快速编辑（列表点击弹出） | 深度编辑（独立页面） |
| 内容区 | 与全屏完全相同 | 与弹出完全相同 |

### 2.2 参考页面结构（自上而下）

```
顶部栏：[项目图标] 项目名 [下拉双箭头]      [优先级旗帜] [⋯ 三点菜单]
内容区：
  ① 日期与提醒行：[日历图标] "日期与提醒"（浅灰占位，点击展开）
  ② 任务标题：20–22sp 加粗，无边框纯文本
  ③ 任务描述：14–16sp 常规，无边框，紧贴标题（4–8px）
  ④ 子任务列表：○ 圆形复选框 + 文字 + ≡ 拖拽手柄；行间极细分割线
  ⑤ 标签区：pastel 药丸（淡黄/淡粉），大圆角
底部工具栏：[标签] [子任务] [附件]（线条图标，常驻底部）
```

### 2.3 参考关键交互

- **无保存按钮，自动保存**（编辑即保存，离开即落库）。
- 项目名旁下拉双箭头：编辑中直接切换所属项目。
- 优先级：顶部栏旗帜图标（单一入口，不散落表单）。
- 子任务：圆形复选框 + 右侧拖拽手柄（≡）。
- 标签：柔和 pastel 药丸。
- 附件：底部工具栏回形针图标。

## 3. 现状盘点

### 3.1 两个编辑面

| 面 | 触发 | 结构 |
|---|---|---|
| `TaskCreateSheet`（底部弹窗） | FAB / 日历点日期 | 顶部栏（项目名+下拉+旗帜+⋯）+ 标题 + 选项行（日期/优先级/标签）+ 描述/备注（⋯菜单开关）+ 子任务（圆复选框+拖拽+删除）+ **自动保存** |
| `TaskEditPage`（全屏页） | 点击任务 / 树菜单「新建子任务」 | AppBar（编辑/新建任务 + 保存按钮）+ 分区卡片（标题/项目下拉/描述+备注/开始+截止/优先级/状态 chips/标签/父任务只读）+ **显式保存** |

### 3.2 与参考图差距

| # | 差距 | 说明 |
|---|---|---|
| G1 | 两编辑面视觉/结构不统一 | create sheet 已滴答化；edit page 仍是分区卡片式，风格割裂 |
| G2 | 编辑页无子任务管理 | 无法在编辑已有任务时增删/排序子任务（create sheet 有） |
| G3 | 编辑页顶栏非参考式 | 无「项目名+下拉切换」、无优先级旗帜、无 ⋯ 菜单（无删除/更多操作） |
| G4 | 编辑页显式保存 | 参考为自动保存；`55 §8` 曾定「编辑页保留显式保存」 |
| G5 | 无底部工具栏 | 参考常驻 标签/子任务/附件 三图标（拇指热区） |
| G6 | 描述/备注藏于 ⋯ 菜单 | create sheet 现状；参考内联展示 |
| G7 | 日期两行 vs 参考单行 | 编辑页开始+截止两行；参考单行「日期与提醒」 |
| G8 | 状态 chips 为本项目特有 | 参考无状态字段（用复选框表达完成）；本项目 4 状态 + 派生规则，**必须保留** |
| G9 | 附件功能 v1 无 | 参考底部工具栏含附件；本项目数据模型无附件字段（AGENTS.md §3-5） |

## 4. 已确认决策（D1–D9）

| 决策 | 结论 |
|---|---|
| **D1 方案** | **统一编辑器**：抽共享「任务编辑器」组件，弹出式/全屏式仅呈现容器不同（对齐参考核心结论）；`TaskEditPage` 重构为全屏容器 + 共享编辑器，`TaskCreateSheet` 复用共享编辑器 |
| **D2 保存** | 编辑页**保持显式保存**（AppBar 保存按钮 + 未保存离开提示，55 §8 现状）；新建弹窗保持自动保存 |
| **D3 子任务** | 编辑页**加子任务管理**：新增/删除/拖拽排序，与新建弹窗一致 |
| **D4 删除** | 编辑页顶栏 **⋯ 菜单加删除**（带确认弹窗） |
| **D5 底部工具栏** | **设置项全部移入底部工具栏**（日期/状态/标签/优先级），内容区只留核心内容以节省空间；**附件占位禁用**，等后续功能落地 |
| **D6 日期入口** | 工具栏**单「日期」图标**，弹层内可分别设开始/截止（今天/明天/下周/自定义/清除） |
| **D7 状态位置** | 状态放**工具栏图标**（弹层选择 4 状态；有子任务时禁用 + 派生提示） |
| **D8 备注** | 备注保留 **⋯ 菜单开关**（现状） |
| **D9 描述** | 描述保留 **⋯ 菜单开关**（现状，不内联） |

## 5. 统一编辑器设计（定稿）

### 5.1 共享组件结构

```
顶部栏：[项目图标] 项目名 [下拉双箭头]      [⋯ 三点菜单]
内容区（设置项全部移出，仅留核心内容）：
  ① 任务标题：大号加粗（titleLarge），无边框，自动聚焦
  ② 描述/备注：⋯ 菜单开关后内联展开（默认隐藏，D8/D9）
  ③ 子任务列表：○ 圆形复选框 + 文字 + ≡ 拖拽 + 删除按钮
底部工具栏（常驻，替代原选项行）：
  [日期] [状态] [标签] [优先级] [附件占位禁用]
```

- **项目**：保留在顶部栏（项目名 + 下拉双箭头，参考式），不进工具栏。
- **优先级旗帜**：移入工具栏（D5），顶部栏右侧仅 ⋯ 菜单。
- **日期**：单图标，弹层内分设开始/截止（D6，复用现有 `_DueDateChoice` 预设 + 自定义）。
- **状态**：工具栏图标，弹层选择 4 状态；有子任务时图标禁用 + Tooltip 派生提示（D7，AGENTS.md §3-2）。
- **附件**：占位禁用图标 + Tooltip「即将推出」（D5）。
- **⋯ 菜单**：描述开关 / 备注开关 / 删除（编辑态，带确认弹窗，D4/D8/D9）。

### 5.2 弹出式容器（TaskCreateSheet 改造）

- 保持底部弹窗形态（60–65% 高、顶部圆角、遮罩、键盘上移）。
- 内容区换用共享编辑器；自动保存逻辑保留。
- 子任务区仅 1 级任务展示（parentId 为空时），沿用现状。
- ⋯ 菜单：描述/备注开关（无删除，新建态）。

### 5.3 全屏容器（TaskEditPage 改造）

- AppBar：返回箭头 + 项目名 + 下拉双箭头 + 保存按钮 + ⋯ 菜单（描述/备注开关 + 删除）。
- 内容区换用共享编辑器；显式保存 + 未保存离开拦截保留（D2）。
- 新增子任务管理（D3）+ 删除入口（D4）。
- 父任务（parentId 非空）：顶部栏显示父任务名（只读）或保留信息行，实施时按空间取舍。

## 6. 约束（不可违反）

- i18n：所有新文案走 ARB（`lib/core/l10n/`），改后 `flutter gen-l10n`。
- 设计令牌：颜色/圆角/间距/动效一律 `AppTokens`，禁止魔法值（AGENTS.md §3-9）。
- 状态派生：有子任务的任务状态由子任务派生，控件禁用（AGENTS.md §3-2）。
- 层级上限 3 级；删除 = 本地硬删 + 墓碑（AGENTS.md §3-10）。
- v1 范围外：不做提醒通知、重复任务、多用户、多端同时编辑（AGENTS.md §3-5）；**附件无数据模型字段**。
- 依赖版本锁定，不升级任何依赖（AGENTS.md §3-7）。
