# 滴答清单（TickTick）任务编辑页面设计分析报告

> 基于两张 Android 截图分析（项目内任务编辑页面），聚焦于「新建项目/项目编辑界面」优化的参考依据。

## 1. 整体布局与页面框架

### 1.1 弹出式（底部弹窗）

#### 页面框架
- **触发方式**：从底部弹出，覆盖当前页面约 60-70% 高度
- **遮罩层**：半透明黑色遮罩（约 `rgba(0,0,0,0.4)`），点击可关闭弹窗
- **弹窗本身**：白色背景，顶部圆角（约 20-24px），底部无圆角（贴合屏幕底部）
- **高度**：约 60-70% 屏幕高度，可向上扩展

#### 顶部栏结构
```
[公文包图标] 工作任务 [下拉箭头]          [勾选图标] [更多选项]
```
- **左侧**：公文包图标 + 清单名称（"工作任务"）+ 下拉箭头（表示可切换清单）
- **右侧**：勾选图标（完成/保存）+ 三个点更多选项图标
- **高度**：约 56-64dp
- **背景**：与弹窗背景一致（白色），无分割线

#### 内容区结构
1. **元数据行**：`[日历图标] 日期与提醒`（灰色文字）
2. **标题输入区**：粗体大字（约 18-20sp），无边框
3. **描述输入区**：常规字重（约 14-16sp），无边框
4. **子任务列表区**：带复选框和拖拽手柄的列表
5. **标签区**：药丸形标签，横向排列

#### 底部操作区
- **三个功能图标**：标签、列表、附件
- **高度**：约 48-56dp
- **背景**：白色，与内容区一致
- **图标风格**：线性图标，灰色

### 1.2 全屏式

#### 页面框架
- **页面类型**：标准移动端页面，无遮罩层
- **整体结构**：AppBar + 内容区 + 底部工具栏
- **背景色**：浅灰色（约 `#F5F5F5`）

#### AppBar 结构
```
[返回箭头] [公文包图标] 工作任务 [下拉箭头]    [勾选图标] [更多选项]
```
- **左侧**：返回箭头（←）
- **中间**：公文包图标 + 清单名称 + 下拉箭头
- **右侧**：勾选图标 + 更多选项图标
- **高度**：约 56-64dp
- **背景**：与页面背景一致（浅灰色）

#### 内容区结构
- 与弹出式基本一致，但：
  - 占据整个屏幕高度
  - 内容区有更多垂直空间
  - 标签区和功能图标在页面底部

## 2. 表单字段设计

### 2.1 字段行结构

#### 典型字段行布局
```
[图标] [字段名]                    [右侧值/箭头]
```

#### 具体字段分析

| 字段 | 图标样式 | 文字样式 | 右侧展示 | 说明 |
|------|---------|---------|----------|------|
| **日期与提醒** | 日历图标（灰色线性） | "日期与提醒"（灰色，约 14-16sp） | 无（或点击后展开） | 占位符状态 |
| **清单选择** | 公文包图标（彩色） | "工作任务"（黑色，约 16-18sp） | 下拉箭头（灰色） | 可切换清单 |
| **优先级** | 旗帜图标（推测） | 颜色标记（推测） | 颜色点/文字（推测） | 未在截图显示 |
| **标签** | 标签图标 | 已选标签（药丸形） | 药丸横向排列 | 多选支持 |

### 2.2 字段间距与分隔

#### 字段间间距
- **垂直间距**：约 12-16dp
- **分隔线**：无明显分隔线（依赖间距区分）
- **视觉分组**：通过间距和背景色差异分组

#### 标题输入区
- **字号**：约 18-20sp
- **字重**：Bold (700)
- **占位符**：可能为"任务标题"（灰色）
- **边框**：无明显边框，底部可能有细线
- **多行支持**：是，可输入多行标题

#### 描述/备注区
- **字号**：约 14-16sp
- **字重**：Regular (400)
- **占位符**：可能为"添加描述"（灰色）
- **边框**：无明显边框
- **多行支持**：是，可输入多行描述

### 2.3 子任务区域

#### 子任务行结构
```
[复选框] [子任务标题]                    [拖拽手柄]
```

- **复选框**：圆形，灰色边框，约 20-24px
- **子任务标题**：约 16-17sp，常规字重
- **拖拽手柄**：三条横线图标，灰色，约 24px
- **行间距**：约 8-12dp
- **分隔线**：细线分隔（约 1px，`#F0F0F0`）

## 3. 选项行视觉（重点）

### 3.1 典型选项行样式

#### 结构模板
```
[图标] [文字]                    [右侧值/箭头]
```

#### 视觉特征
- **图标**：左侧，灰色线性图标，约 24px
- **文字**：中间，灰色或黑色，约 14-16sp
- **右侧**：值或箭头，灰色或彩色
- **高度**：约 48-56dp
- **点击区域**：整行可点击

### 3.2 日期/时间选择行

#### 视觉表现
- **图标**：日历图标（灰色线性）
- **文字**："日期与提醒"（灰色，约 14-16sp）
- **右侧**：无（占位符状态）或日期文字
- **展开后**：底部日期选择器（今天/明天/下周/自定义）

### 3.3 优先级选择行

#### 视觉表现（推测）
- **图标**：旗帜图标（灰色线性）
- **文字**："优先级"（灰色）
- **右侧**：颜色标记（红/橙/蓝/无）
- **交互**：点击循环切换或展开选择

### 3.4 标签选择行

#### 视觉表现
- **图标**：标签图标（灰色线性）
- **文字**："标签"（灰色）
- **右侧**：已选标签药丸（横向排列）
- **药丸样式**：
  - 圆角：完全圆形或大圆角药丸形
  - 背景色：柔和的彩色（淡黄、淡粉等）
  - 文字：深色，约 12-14sp
  - 间距：药丸间约 8dp

### 3.5 清单/项目选择行

#### 视觉表现
- **图标**：公文包图标（彩色）
- **文字**：当前清单名（黑色，约 16-18sp）
- **右侧**：下拉箭头（灰色）
- **交互**：点击弹出"移动到"底部弹窗

## 5. 交互细节

### 5.1 关闭/保存行为

#### 弹出式
- **关闭方式**：
  1. 点击遮罩层关闭
  2. 向下滑动关闭
  3. 点击右上角勾选图标保存并关闭
- **保存逻辑**：
  - 自动保存（失去焦点或关闭时保存）
  - 标题为空则丢弃或提示

#### 全屏式
- **关闭方式**：
  1. 点击左上角返回箭头
  2. 系统返回键
- **保存逻辑**：
  - 可能自动保存或点击勾选图标保存
  - 未保存时可能提示确认

### 5.2 键盘适配

#### 弹出式
- **内容区滚动**：保持输入框可见
- **弹窗移动**：随键盘上移（`isScrollControlled` + `viewInsets`）
- **底部工具栏**：固定在键盘上方

#### 全屏式
- **内容区滚动**：标准滚动行为
- **AppBar**：可能隐藏或压缩

### 5.3 按钮样式

#### 主操作按钮
- **勾选图标**：白色或灰色，约 24-28px
- **位置**：右上角
- **触控目标**：约 48x48dp

#### 次操作按钮
- **更多选项**：三个点图标，灰色
- **位置**：右上角，勾选图标右侧
- **触控目标**：约 48x48dp

#### 功能图标
- **标签/列表/附件**：底部三个图标
- **样式**：线性图标，灰色，约 24px
- **间距**：图标间约 16-24dp

### 5.4 拖拽交互

#### 拖拽手柄
- **图标**：三条横线
- **位置**：子任务行右侧
- **交互**：长按拖动排序
- **视觉反馈**：拖动项半透明 + 阴影

## 6. 对本项目（Flutter 待办 App）优化「新建项目/项目编辑」的借鉴要点

### 6.1 本项目当前项目表单现状

根据 `55-ui-redesign-proposal.md`，本项目当前项目表单为：
- **简单对话框**：项目名称输入 + 颜色选择 + 确定/取消按钮
- **无选项行结构**：缺乏日期、优先级、标签等字段
- **视觉层次单一**：无明显的字段分组和视觉层次

### 6.2 值得借鉴的设计元素

#### 1. 字段排布结构
- **借鉴**：`[图标] 字段名 …… 右侧值/箭头` 的行结构
- **应用**：项目编辑可增加描述、颜色、图标等选项行
- **优势**：视觉清晰，易于扩展

#### 2. 选项行视觉
- **借鉴**：统一的选项行高度（48-56dp）、图标+文字+右侧值的布局
- **应用**：项目颜色选择、项目图标选择、项目描述等
- **优势**：一致性好，用户学习成本低

#### 3. 视觉层次
- **借鉴**：通过间距、背景色、圆角创造层次
- **应用**：
  - 弹窗顶部圆角（20-24px）
  - 白色内容区 + 浅灰背景
  - 字段间明确的间距（12-16dp）
- **优势**：信息层级清晰，减少视觉疲劳

#### 4. 标签药丸样式
- **借鉴**：圆角药丸形标签，柔和的背景色
- **应用**：项目标签（如"工作"、"个人"）
- **优势**：视觉友好，易于识别

#### 5. 自动保存机制
- **借鉴**：失去焦点或关闭时自动保存
- **应用**：项目编辑无需显式保存按钮
- **优势**：操作流畅，减少用户步骤

### 6.3 结合本项目特点的调整建议

#### 1. 项目表单字段扩展
当前项目只有名称+颜色，建议扩展为：
```
[图标] 项目名称                    [输入框]
[颜色圆点] 项目颜色                [颜色选择器]
[图标] 项目描述                    [多行输入]
[标签] 项目标签                    [药丸多选]
```

#### 2. 移动端优先 + 桌面自适应

**移动端（<600dp）**：
- 使用底部弹窗（参考滴答清单弹出式）
- 顶部栏：返回/关闭 + 标题 + 保存
- 内容区：选项行结构
- 底部：功能图标（标签、颜色、描述）

**桌面端（≥600dp）**：
- 使用居中对话框
- 保持选项行结构
- 增加更多字段空间

#### 3. 颜色选择优化
当前颜色选择为简单颜色网格，建议优化为：
- **选项行结构**：`[颜色圆点] 项目颜色 [当前颜色]`
- **点击展开**：底部颜色选择器
- **预设颜色**：提供常用颜色
- **自定义颜色**：支持自定义色值

#### 4. 项目图标系统
滴答清单使用 emoji 作为清单图标，建议本项目支持：
- **预设图标**：提供常用图标（文件夹、书本、公文包等）
- **颜色关联**：图标颜色与项目颜色一致
- **选项行结构**：`[当前图标] 项目图标 [下拉箭头]`

#### 5. 视觉一致性
- **圆角系统**：使用设计令牌（`radiusCard=16`, `radiusDialog=24`）
- **颜色系统**：使用 Material 3 动态色（`seedColor=#3482FF`）
- **字体层级**：遵循 `50-ui-ux.md` 定义的字体令牌

#### 6. 交互优化
- **自动保存**：失去焦点或关闭时自动保存
- **校验反馈**：标题为空时的提示
- **键盘适配**：弹窗随键盘上移
- **拖拽排序**：项目列表支持拖拽排序

### 6.4 具体实施建议

#### 项目编辑弹窗结构（移动端）
```
顶部栏：[X] 项目编辑                [保存]
├─ 选项行：[图标] 项目名称          [输入框]
├─ 选项行：[颜色圆点] 项目颜色      [当前颜色]
├─ 选项行：[图标] 项目描述          [多行输入]
├─ 选项行：[标签] 项目标签          [药丸多选]
└─ 底部：[图标] [图标] [图标]       (标签、颜色、描述快捷入口)
```

#### 项目编辑对话框结构（桌面端）
```
标题栏：项目编辑                    [X]
├─ 选项行：[图标] 项目名称          [输入框]
├─ 选项行：[颜色圆点] 项目颜色      [颜色选择器]
├─ 选项行：[图标] 项目描述          [多行输入]
├─ 选项行：[标签] 项目标签          [药丸多选]
└─ 按钮栏：[取消]                  [保存]
```

### 6.5 与现有设计系统的整合

#### 设计令牌应用
- **圆角**：`radiusDialog=24`（弹窗）、`radiusCard=16`（内容区）
- **间距**：`spaceMd=16`（字段间距）、`spaceSm=12`（内部间距）
- **颜色**：`surfacePage=#F2F4F7`（背景）、`#FFFFFF`（内容区）
- **字体**：`textTitle=20/w600`（标题）、`textBody=16/w400`（正文）

#### 组件复用
- **选项行组件**：创建统一的 `OptionRow` 组件
- **标签药丸组件**：复用现有的 `TagChip` 组件
- **颜色选择器**：创建 `ColorPickerSheet` 底部弹窗
- **图标选择器**：创建 `IconPickerSheet` 底部弹窗
