# 57 — 通用任务页细节优化（定稿）

> 状态：**FINAL — 已与用户讨论定稿（2026-08-12）**。用户新需求两项：① 精简窄屏底部导航栏（标签移入抽屉，仅留今日/日历，紧凑化并保留扩展空间）；② 项目任务显示从「每任务一卡片」改为「一级任务一卡片 + 内部子任务行」。
> 本文档是实施唯一依据；改代码必同步 `50-ui-ux.md` / `10-requirements.md` / `70-milestones.md`。

## 1. 需求

1. **精简窄屏底栏**：原底部 NavigationBar（今日/日历/标签 3 入口）中「标签」功能被侧边栏抽屉覆盖，移除；**保留今日/日历 2 项**，底栏**紧凑化**（占用空间小），并**为将来新增功能按钮保留扩展空间**。
2. **美化项目任务显示**：项目作用域从「每个任务一张卡片行（TaskTree 平铺）」改为「**每个一级任务一张卡片**，展开卡片后显示下级任务」，样式借鉴 `TaskCreateSheet` 视觉语言。

## 2. 现状分析

### 2.1 底栏 vs 侧边栏（需求 1）

| 导航入口 | 窄屏底栏 | 侧边栏抽屉 |
|---|---|---|
| 今日 | ✅ | ✅（系统组） |
| 日历 | ✅ | ✅（系统组） |
| 标签 | ✅ | ✅（系统组） |
| 收件箱 | ❌ | ✅（系统组） |
| 项目列表 | ❌ | ✅（项目组，逐项列出） |
| 新建项目 | ❌ | ✅（底部入口） |
| 搜索/设置 | AppBar 图标 | AppBar 图标（两者共用） |

**结论**：底栏中「标签」入口被抽屉覆盖，移除；**保留今日/日历 2 项**（用户决策：保留快捷入口但精简，底栏紧凑化，为将来功能按钮留扩展空间）。宽屏本无底栏（仅 NavigationRail）。

### 2.2 项目任务显示（需求 2）

- 当前：`TaskTree` 平铺 ListView，**每个任务一行** `TaskRow` 卡片（含子任务也各自成行、缩进显示、拖拽调级）。
- 目标：**一级任务 = 大卡片**（头部：勾选/标题/标签/时间/进度/展开箭头）；**展开后卡片内平铺子任务行**（子行可再缩进展开 3 级）。

## 3. 已确认决策（D1–D7）

| 决策 | 结论 |
|---|---|
| D1 卡片内子任务形态 | **一级卡片 + 内部子任务行**（一级=大卡片，子级=紧凑行，可再缩进展开三级） |
| D2 拖拽保留 | **完整保留**：一级卡片长按拖拽排序；卡片内子任务行拖拽调级/排序（FR-TSK-06/07 + 深度/防环校验） |
| D3 展开/折叠默认态 | **默认全展开**（沿用 TaskTree 现有 `expandState` 行为，用户可手动折叠） |
| D4 样式参考程度 | **借鉴视觉语言**：白卡/圆角令牌/选项行（图标+文字+右侧值）风格/紧凑行，不照搬弹窗结构 |
| D5 底栏取舍 | **保留今日/日历 2 项**，标签移除（移入抽屉）；底栏**紧凑化**（占用空间小）；**为将来新增功能按钮保留扩展空间** |
| D6 一级卡片头部 | **不加子任务数**（进度环已含完成度信息） |
| D7 子任务行视觉 | **紧凑行**（无卡片底，Divider 分隔），确认符合预期 |

## 4. 方案设计

### 4.1 需求 1：精简窄屏底栏

- `app_shell.dart`：底栏从 3 项（今日/日历/标签）**精简为 2 项（今日/日历）**，移除标签入口（其抽屉入口保留）。
- **紧凑化**：底栏占用空间减小——考虑改用更紧凑的容器（如降低 NavigationBar 高度、减小 padding/图标间距），或自绘轻量底栏（图标 + 极小文字，如滴答式紧凑栏）。具体实现由实施者按令牌给出方案，**目标是明显比标准 NavigationBar（高 80dp）更矮**。
- **扩展性**：底栏容器保持「可容纳后续新增功能按钮」的结构（不写死 2 项，用列表渲染 + 注释说明扩展方式）。
- 保留：宽屏 NavigationRail（5 目的地，不变）；AppBar（汉堡 + 标题 + 搜索/设置 + 作用域专属操作）。
- `10-requirements.md` `FR-NAV-01`：更新为「窄屏底部 2 项精简导航（今日/日历）+ 侧边栏抽屉 + 宽屏 NavigationRail」。
- **测试**：`widget_test.dart` 中底栏用例更新（3-tab → 2-tab；删除标签 tab 断言；新增紧凑高度断言）。

### 4.2 需求 2：一级任务卡片化（`TaskTree` 重构）

**结构**：

```
项目作用域 ListView
└─ 一级任务卡片（白卡：radiusCard + 轻阴影，默认展开）
   ├─ 卡片头部：勾选 + 标题 + 标签 chips + 时间 + 进度环 + 展开/折叠箭头 + 行菜单
   └─ 展开区（卡片内缩进区）：
       ├─ 二级任务行（紧凑行）
       │   └─ （若二级有子任务）展开区 → 三级任务行
       └─ 二级任务行 ...
```

**要点**：
- **一级卡片** = 复用 `TaskRow` 的视觉 + 增强：头部含勾选/标题/元信息/进度环/展开箭头/菜单；卡片背景 `surfaceCard` + 阴影（沿用令牌）。
- **内部子任务行** = 紧凑 `TaskRow` 变体（缩进 + 小圆角或无卡片底，用 Divider 分隔，借鉴 TaskCreateSheet 的行间距节奏）。
- **展开/折叠**：沿用 `treeExpandProvider` 状态（D3 默认全展开不变）。
- **拖拽（D2 完整保留）**：
  - 一级卡片头部长按拖动 → 同级排序（复用现有 DragTarget/LongPressDraggable 逻辑）。
  - 卡片内子任务行长按拖动 → 排序/调级/回 1 级（沿用 `_fitsDepthLimit` 深度校验 + 防环）。
  - 拖拽反馈、非法目标红色高亮、回弹提示全部保留。
- **菜单**：一级卡片与子行的「编辑/新建子任务/上移/下移/缩进/缩出/删除」菜单逻辑复用现有 `_handleMenuAction`。

**视觉语言借鉴（D4）**：白卡（`surfaceCard`）+ 圆角（`radiusCard`/`radiusList`）+ 轻阴影令牌；子任务行间距紧凑（`spaceXxs`/`spaceXs`）；Divider 分隔行（参考 TaskCreateSheet）；全部走 `AppTokens`，无魔法值。
