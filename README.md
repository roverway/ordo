## ✨ 核心特性

1. **清晰的四态生命周期**：
   - 待办（Todo）→ 进行中（In Progress）→ 已完成（Done）/ 已放弃（Dropped），支持一键激活、完成与重启。
2. **三级结构化任务树**：
   - 项目（Project）→ 任务（Task）→ 子步骤（Sub-step），父任务进度根据子项完成情况自动衍生计算。
3. **多维分类体系**：
   - 收集箱（Inbox）、文件夹分类、独立项目管理以及多标签（Tag）快速过滤。
4. **四象限视图（艾森豪威尔矩阵）**：
   - 深度融合四象限时间管理法则，提供 2x2 矩阵全景与单列聚焦列表双模式；跨象限拖拽纯属性流转（仅调优先级与截止时间，保持清单与层级绝对不变）；多层级文件夹/清单范围级联筛选与环形进度环联动。
5. **全景日历与传统历法**：
   - 月视图日程排布、农历、二十四节气与法定节假日调休（班/休）标识，任务按计划截止日直观分布。
6. **多层级个性化背景壁纸与毛玻璃防花屏系统**：
   - 支持应用全局壁纸与项目清单专属壁纸双层级管理；内置低饱和度质感预设，支持本地图片沙箱隔离存储；提供透明度遮罩与高斯模糊调节，配合自适应磨砂半透明毛玻璃材质（Glassmorphism），保障 WCAG 高对比度文字可读性。
7. **安全可靠的云端同步**：
   - 支持 WebDAV 与兼容 S3 协议（如 MinIO、阿里云 OSS、AWS S3 等）对象存储，采用中继合并策略保障离线优先与多端合并。
8. **完备的数据容灾保障**：
   - 本地快照历史池随时一键回滚；支持导出加密/明文 `.ordobak` 备份包与外部恢复。
9. **优雅的设计与交互**：
   - 8 款精美自然主题色板，自适应深浅模式；移动端全手势滑动操作与宽屏双栏侧边面板。

## 🛠️ 技术栈

- **前端框架**：Flutter (Target: Android, iOS, macOS, Windows, Linux, Web)
- **状态管理**：Riverpod (flutter_riverpod)
- **本地数据库**：Drift (SQLite3 响应式流)
- **路由导航**：GoRouter
- **国际化**：Flutter Gen-l10n (zh / en)
- **安全存储**：flutter_secure_storage
